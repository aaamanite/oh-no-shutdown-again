OT security simulator · Chapter 01

Substation Sentinel

You are the new OT security lead at Kestrel Point, a 132/33 kV substation run by Northwind Grid Co. It feeds 12,400 homes and St. Brigid Hospital. Attackers have noticed.

  • Keep the lights on. Every energized feeder earns revenue. Outages cost money, reliability and regulator fines.
  • Invest in controls. Asset inventory, monitoring, segmentation, MFA, backups — each one prevents or exposes real attack techniques.
  • Triage incidents. Read what each system logged, tag what is the attack, then play a response card. Overreacting is a failure too.
